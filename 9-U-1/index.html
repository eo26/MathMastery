Chapter 9 · Probability

Random Variables and Distributions

A random variable turns each outcome into a number. Its distribution says how the probability is shared among those numbers: where it sits (the mean), how widely it spreads (the variance), and what happens when you rescale or add random quantities.

On this page

  • Read the cumulative distribution function (CDF), F(x) = P(X ≤ x), and use it for P(a < X ≤ b).

1A random variable is a function

Roll two dice. The sample space has 36 outcomes, pairs like (3, 4). Often we don’t care about the pair itself, only a number computed from it: the total, the larger die, the gap between them. A random variable is exactly that: a rule X that assigns a number X(ω) to every outcome ω. For the total, X(3, 4) = 7. Despite the name, a random variable isn’t random and isn’t a variable; it’s a fixed function. The randomness is in which outcome happens.

Several outcomes can give the same number: (1, 6), (2, 5), …, (6, 1) all give 7. The event “X = 7” is that group of outcomes, and its probability is P(X = 7) = 6/36. A random variable whose values can be listed (here 2, 3, …, 12) is discrete. Continuous random variables, like an exact waiting time, come in 9.U.4.

2The probability mass function

Collecting P(X = x) for every value x gives the probability mass function (PMF), p(x) = P(X = x). Each outcome’s probability lands on exactly one value, so the PMF is never negative and adds up to 1. The PMF, or anything equivalent to it, is the random variable’s distribution. Two different random variables (the total of two dice, and a weird spinner) can have the same distribution; for probability questions, the distribution is all that matters.

3The cumulative distribution function

The cumulative distribution function (CDF) adds the PMF up from the left: F(x) = P(X ≤ x). For a discrete random variable it’s a staircase. It is flat between values, jumps up at each value by exactly p(x), starts at 0 far to the left and ends at 1 far to the right. Because X ≤ b splits into X ≤ a and a < X ≤ b,

\[ P(a < X \le b) = F(b) - F(a), \qquad P(X = x) = \text{the size of the jump at } x. \]

Mind the ends. With whole-number values, P(X < 5) = P(X ≤ 4) = F(4), not F(5). The filled and open dots on the staircase show which side of each jump a value belongs to. The CDF matters more later: continuous random variables have no PMF, but every random variable has a CDF.

4Mean and variance

The mean μ = E(X) = Σ x p(x) from 9.B.5 says where the distribution balances. It says nothing about spread: a fair die and a die whose faces read 3, 3, 4, 4, 3, 4 both have mean 3.5. To measure spread, average the squared distance from the mean. That’s the variance:

\[ \operatorname{Var}(X) = E\big[(X-\mu)^2\big] = \sum_x (x-\mu)^2\, p(x) = E(X^2) - \mu^2. \]

The last form, “mean of the square minus square of the mean”, is often quicker by hand. Squaring makes every distance count positively, and big distances count extra. Because it squares, the variance is in squared units (goals²); its square root, the standard deviation σ = √Var(X), is back in the original units and works as a “typical distance from the mean”. For many distributions, most of the probability sits within about two standard deviations of the mean. E(X²) is called the second moment; moments are the subject of 9.U.6.

5Rescaling: aX + b

Convert tomorrow’s forecast high from °C to °F: Y = 1.8X + 32. Every value is stretched by 1.8 and then shifted by 32, so the mean does the same, but the spread is only stretched: shifting everything by 32 doesn’t move anything further apart. This is a linear transformation:

\[ E(aX+b) = a\,E(X) + b, \qquad \operatorname{Var}(aX+b) = a^2 \operatorname{Var}(X), \qquad \sigma_{aX+b} = |a|\,\sigma_X. \]

The variance picks up a², because it is built from squared distances: double every distance and the squares quadruple.

6Adding independent random variables

Two random variables are independent when knowing one tells you nothing about the other, like two separate dice. For any random variables, means add: E(X + Y) = E(X) + E(Y). For independent ones, variances add too:

\[ \operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y), \qquad \operatorname{Var}(X-Y) = \operatorname{Var}(X) + \operatorname{Var}(Y). \]

Standard deviations do not add: the SD of a sum of two independent copies is √2 σ ≈ 1.41σ, not 2σ, because highs on one partly cancel lows on the other. The distribution of the sum comes from adding up every pair of values, weighted by the product of their probabilities. That operation is called a convolution; it’s how two flat dice make the triangle for the total. In the explorer, choose “X₁ + X₂” to see it.

7Exact distributions by computer

Convolving by hand gets tedious fast. Here is the exact distribution of the total of five dice, using fractions so nothing is rounded:

from fractions import Fraction                          # exact fractions, no rounding
die = {k: Fraction(1, 6) for k in range(1, 7)}          # PMF of one fair die: value -> probability
def add(p, q):                                          # PMF of X + Y for independent X and Y (a convolution)
    r = {}                                              # the result: value -> probability
    for x, px in p.items():                             # every value of X...
        for y, qy in q.items():                         # ...paired with every value of Y
            r[x + y] = r.get(x + y, 0) + px * qy        # independent: multiply, then pile onto x + y
    return r
total = die                                             # start with one die
for _ in range(4):                                      # add four more dice
    total = add(total, die)
mean = sum(x * p for x, p in total.items())             # E = 5 × 3.5 = 35/2
var = sum((x - mean)**2 * p for x, p in total.items())  # Var = 5 × 35/12 = 175/12 (variances add)
print(total[17], mean, var)                             # 65/648  35/2  175/12

The distribution of five dice already looks like a bell. That’s no accident; it’s the central limit theorem (9.U.7) starting to show.

8Traps

Compare

Easy to get wrong

✕ Var(2X) = 2 Var(X)

Doubling a die’s values doubles every distance from the mean, so the SD doubles and the variance (squared distances) quadruples: Var(2X) = 4 Var(X).

✕ Var(X − Y) = Var X − Var Y

The difference of two dice is just as spread out as the sum: both have variance 35/6. Subtracting an independent random quantity adds uncertainty, it never removes it.

✕ SDs add

One die has σ ≈ 1.71. The total of two independent dice has σ ≈ 2.42 = √2 × 1.71, not 3.42. Variances add; standard deviations add like the sides of a right triangle.

9Now, in symbols

A discrete random variable X : Ω → ℝ with values x₁, x₂, … has

\[ p(x) = P(X = x) = P(\{\omega : X(\omega) = x\}), \qquad p(x) \ge 0, \quad \sum_x p(x) = 1 \]
\[ F(x) = P(X \le x) = \sum_{t \le x} p(t), \qquad P(a < X \le b) = F(b) - F(a) \]
\[ \mu = E(X) = \sum_x x\,p(x), \qquad \operatorname{Var}(X) = \sum_x (x-\mu)^2 p(x) = E(X^2) - \mu^2, \qquad \sigma = \sqrt{\operatorname{Var}(X)} \]
\[ E(aX+b) = aE(X)+b, \qquad \operatorname{Var}(aX+b) = a^2\operatorname{Var}(X) \]
\[ X, Y \text{ independent: } \operatorname{Var}(X \pm Y) = \operatorname{Var}(X) + \operatorname{Var}(Y), \qquad p_{X+Y}(s) = \sum_x p_X(x)\, p_Y(s - x) \]

E(X + Y) = E(X) + E(Y) holds for all random variables; the variance rule needs independence (9.U.5 adds the covariance term for the general case).

11Words to know

Random variableA function X that gives a number to each outcome of an experiment.
Discrete random variableOne whose possible values can be listed.
Probability mass function (PMF)p(x) = P(X = x), for each value x. Never negative, adds to 1.
DistributionHow the probability is shared among the values: the PMF, or equivalently the CDF.
Cumulative distribution function (CDF)F(x) = P(X ≤ x): a staircase from 0 up to 1.
Meanμ = E(X), the balance point of the distribution.
VarianceVar(X) = E[(X − μ)²], the average squared distance from the mean.
Standard deviationσ = √Var(X), a typical distance from the mean, in the original units.
MomentE(Xᵏ); E(X²) is the second moment.
Linear transformationY = aX + b: stretch by a, then shift by b.
Independent random variablesKnowing the value of one doesn’t change the distribution of the other.
ConvolutionThe rule that gives the distribution of a sum of independent random variables.
Sample space / functionFrom 9.B.1 and chapter 3: the outcomes, and a rule giving one output for each input.
