Rational Expressions and Functions

Divide one polynomial by another and you get fractions with x in them. They follow the same rules as 1.B.3’s fractions, and their graphs are shaped by one thing you can never do: divide by zero.

Basics you are here Undergraduate Masters

On this page

  • Read a rational expression p(x)/q(x) and find its domain: every x except the zeros of the bottom.
  • Simplify by cancelling common factors (never terms), and multiply, divide, add and subtract with a least common denominator.
  • Read the graph of a rational function from its factors: vertical asymptotes, holes, x-intercepts, and the horizontal or slant asymptote.
  • Solve rational equations and throw out extraneous solutions that would divide by zero.
  • Use rational functions for work rates, average cost, mixtures and average speed.

1Fractions with x in them

A rational expression is one polynomial divided by another, like (x + 1)/(x − 2). Just as a fraction is a ratio of whole numbers (1.B.3), this is a ratio of polynomials, hence “rational”. A rational function is y = p(x)/q(x).

One rule rules them all: you can’t divide by zero. So the domain is every x except where the bottom is 0. For (x + 1)/(x − 2), x = 2 is excluded. What happens near x = 2 is the most interesting part of the graph: try x = 2.1, 2.01, 2.001. The bottom gets tiny, 0.1, 0.01, 0.001, while the top stays about 3, so y = 30, 300, 3000: it shoots off to infinity. The graph hugs the vertical line x = 2 without touching it, a vertical asymptote.

Far from the origin something calmer happens. For x = 1000, (1001)/(998) ≈ 1.003: top and bottom are both about x, so y settles towards 1, a horizontal asymptote y = 1. And where the top is 0 (and the bottom isn’t), y = 0: an x-intercept at x = −1. Every feature comes from a factor.

2Graphs are made of factors

Factor the top and the bottom (3.B.8) and every feature can be read off:

  • A factor only on the bottom, like x − 2, gives a vertical asymptote at x = 2. If it appears an odd number of times the graph jumps from +∞ to −∞ across it; an even number of times and both sides go the same way.
  • A factor only on the top, like x + 1, gives an x-intercept at x = −1.
  • A factor on both, like x − 1 in (x − 1)(x + 2)/(x − 1), cancels: the graph is the line y = x + 2, except that x = 1 is still not allowed. There’s a single missing point, a hole, at (1, 3).
  • The degrees decide the far-away behaviour. Top degree smaller than bottom: y → 0. Equal degrees: y → (leading coefficient of top) ÷ (leading coefficient of bottom). Top one degree bigger: the graph approaches a slanted line, a slant asymptote, found by polynomial long division.

3Simplify, multiply, divide, add

All the fraction rules from 1.B.3 carry over, with factors playing the role of prime factors.

  • Simplify by cancelling factors common to top and bottom: (x + 2)(x − 1)/((x − 1)(x + 3)) = (x + 2)/(x + 3), for x ≠ 1. Only factors cancel, never terms: (x + 3)/(x + 5) is not 3/5.
  • Multiply tops and bottoms, then cancel. Divide by flipping the second fraction and multiplying.
  • Add or subtract over a common denominator. The least common denominator (LCD) uses each bottom factor as many times as it appears in any one denominator: for 1/x + 1/(x + 1) it’s x(x + 1), and the sum is ((x + 1) + x)/(x(x + 1)) = (2x + 1)/(x(x + 1)).

The answer is only valid where every original denominator was nonzero, even if a cancelled factor no longer shows it.

    4Rational equations

    To solve an equation with fractions, multiply both sides by the LCD to clear them, then solve the polynomial equation that’s left. But multiplying by an expression that can be zero can create extraneous solutions, as squaring did in 3.B.10. For example:

    \[ \frac{x}{x-2} = \frac{2}{x-2} \;\Rightarrow\; x = 2. \]

    But x = 2 makes both denominators zero: it isn’t in the domain, so the equation has no solution. On the graph, the two sides are the curve y = x/(x − 2) and the curve y = 2/(x − 2), and they never meet. Always check answers against the excluded values.

    6Traps and non-examples

    Compare

    Easy to get wrong

    ✕ (x + 3)/(x + 5) = 3/5

    The x’s are terms, not factors, so they don’t cancel. Test x = 5: 8/10 = 0.8, not 0.6. The real graph (purple) only creeps towards 1, while 3/5 is a flat line.

    ✕ The hole disappears

    (x² − 1)/(x − 1) simplifies to x + 1, but x = 1 is still forbidden: the graph is the line with one point missing at (1, 2). A hole, not an asymptote.

    ✕ x/(x − 2) = 2/(x − 2) ⇒ x = 2

    Clearing the fractions gives x = 2, but that divides by zero. The two curves never meet (they only approach each other near the asymptote): no solution.

    9Words to know

    Rational expressionA polynomial divided by a polynomial, such as (x + 1)/(x − 2).
    Rational functiony = p(x)/q(x).
    DomainThe x-values allowed: all except zeros of the denominator.
    Excluded valueAn x that makes a denominator zero.
    Cancel common factorsDivide top and bottom by a shared factor; terms never cancel.
    Least common denominatorThe smallest product of factors that every denominator divides.
    Vertical asymptoteA line x = a the graph runs up or down along, from a factor (x − a) left on the bottom.
    HoleA single missing point, from a factor cancelled from top and bottom.
    Horizontal asymptoteA line y = c the graph approaches far to the left and right.
    Slant asymptoteA slanted line approached far out, when the top’s degree is one more than the bottom’s.
    Polynomial long divisionDividing polynomials like numbers, giving a quotient and a remainder.
    Rational equationAn equation with the unknown in a denominator.
    Extraneous solutionA value from the solving steps that makes a denominator zero, so it must be rejected.
