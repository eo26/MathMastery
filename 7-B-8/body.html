Chapter 7 · Linear Algebra

Systems of Equations as Matrices

A whole system of equations fits in one line, Ax = b, and it can be read as two pictures: lines that cross, or arrows that add up.

Basics you are here Undergraduate Masters

On this page

  • Write any system of linear equations as one matrix equation Ax = b, and as an augmented matrix [A | b].
  • See the same system two ways: the row picture (one line per equation, the answer is where they cross) and the column picture (the answer is how much of each column it takes to reach b).
  • Tell from det A how many solutions there are: exactly one when det ≠ 0; none or infinitely many when det = 0.
  • Solve with x = A−1b, or with Cramer’s rule, a ratio of two areas.

1One equation per row

In 3.B.6 you solved systems like this one:

2x + y = 5
x − y = 1

Look only at the numbers. Put the numbers in front of x and y into a matrix, the coefficient matrix A; stack the unknowns into the unknown vector x; stack the right-hand sides into the right-hand side vector b. The whole system becomes

211−1xy = 51   or   Ax = b.

Why does that work? Multiplying a matrix by a vector (7.B.5) takes each row of A times the vector: the top row gives 2x + 1y, the bottom row gives 1x − 1y. So each row of A is one equation. A missing variable gets a 0, and every variable must stay in its own column (all the x’s on the left, all the y’s on the right).

When you only want the numbers, drop the letters and keep b next to A behind a bar. That’s the augmented matrix [A | b], the form row reduction works on in 7.B.9:

2Two pictures of the same system

Read A by rows and each equation is a line; a solution is a point on both lines, so it’s where they cross. That’s the row picture, the one from 3.B.6.

Read A by columns and you get something new. Ax means “x times column 1 plus y times column 2” (7.B.4), so the system asks: how much of each column does it take to reach b? Adding stretched copies of vectors is called a linear combination, and this is the column picture. On the moved grid of A, the answer is simply the grid coordinates of b.

The two pictures always agree, because they’re the same arithmetic read two ways. The row picture lives in the plane of answers (x, y). The column picture lives in the plane of targets b, and the matrix A carries one plane to the other: it sends the answer (x, y) to the target b. Solving the system means running A backwards, which is exactly what A−1 does (7.B.7).

3The determinant decides how many

Try the last three presets above.

  • det ≠ 0: exactly one solution, for every b. The two lines cross at one point. The columns point in different directions, so their moved grid covers the whole plane and every b sits on exactly one pair of grid coordinates. In symbols, x = A−1b.
  • det = 0 and b off the line: no solution. The two equations describe parallel lines that never meet. In the column picture both columns lie on one line, and no amount of them can leave it, so a b off that line can’t be reached.
  • det = 0 and b on the line: infinitely many solutions. The two equations describe the same line, so every point on it works. In the column picture, there are endless ways to mix the two columns to reach b.

So when det = 0 the matrix alone can’t tell you which: you have to look at b. And “Nearly parallel” shows a practical warning: when det is close to 0, a tiny nudge to b sends the crossing point flying, so measured data can give wildly wrong answers.

4Solving: the inverse, or Cramer’s rule

When det ≠ 0, the answer is x = A−1b, using swap, change signs, divide (7.B.7). For the system in §1, det = 2·(−1) − 1·1 = −3 and

x = (1/−3) −1−1−1251 = (1/−3)−6−3 = 21.

There’s a shortcut for a single unknown, called Cramer’s rule: to get x, replace column 1 of A by b, take that determinant, and divide by det A. For y, replace column 2 instead.

x = det[b col 2] / det A,    y = det[col 1 b] / det A

It looks like a magic trick, but it’s a picture about areas (7.B.6). The parallelogram on b and column 2 has area det[b col 2]. Now slide b along the direction of column 2 until it lands on column 1’s line. Sliding a side along the other side is a shear, which never changes area. Where does b land? Since b = x·col 1 + y·col 2, removing the y·col 2 part leaves x·col 1. So the parallelogram on b and col 2 has the same area as the one on x·col 1 and col 2, which is x times det A.

Cramer’s rule is handy for 2×2 systems and for proofs. For big systems it’s far too slow (every determinant is a lot of work), and computers use row reduction instead (7.B.9).

7Bigger systems: traffic in a small town

Nothing about Ax = b needs exactly two unknowns. Three equations in three unknowns give a 3×3 matrix; each equation is now a flat plane in 3D, and a single solution is the one point where three planes meet (7.B.10). The same rule holds: if det A ≠ 0 there’s exactly one solution, x = A−1b; if det A = 0 there are none or infinitely many.

Here’s a real-looking 3×3 system with det = 0. Three one-way streets join junctions P, Q and R. Cars per hour enter and leave the town at the junctions, and at every junction, cars in = cars out. That gives one equation per junction:

Explore

Cars in = cars out

The three equations don’t pin the flows down: one street’s flow can be chosen freely. Pick the flow t on the street from P to R (cars per hour) and see what the others must be.

Infinitely many solutions isn’t a mistake here: it reflects a real fact. Cars could go round the long way (P→Q→R) or take the short cut (P→R), and counting cars at the junctions can’t tell how they split. One more measurement, a counter on any one street, settles it. One-way streets add one more rule (no flow can be negative), which narrows the infinitely many solutions to a range.

8Now, in symbols

\[ \begin{cases} a x + b y = e \\ c x + d y = f \end{cases} \iff \begin{bmatrix} a & b \\ c & d \end{bmatrix}\begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} e \\ f \end{bmatrix} \iff x\begin{bmatrix} a \\ c \end{bmatrix} + y\begin{bmatrix} b \\ d \end{bmatrix} = \begin{bmatrix} e \\ f \end{bmatrix} \]
The system, its matrix form, and its column form (a linear combination of the columns).
\[ \det A \neq 0 \;\Longrightarrow\; \mathbf{x} = A^{-1}\mathbf{b} \text{ is the one and only solution} \]
When det A = 0: no solution, or infinitely many, depending on b.
\[ x = \frac{\det\begin{bmatrix} e & b \\ f & d \end{bmatrix}}{\det A} = \frac{ed - bf}{ad - bc}, \qquad y = \frac{\det\begin{bmatrix} a & e \\ c & f \end{bmatrix}}{\det A} = \frac{af - ec}{ad - bc} \]
Cramer’s rule: replace a column by b, divide determinants.

A computer solves systems of any size in one call. It also says when a system has no single answer:

import numpy as np                                     # NumPy: arrays of numbers
A = np.array([[2, 1], [1, -1]])                        # the system 2x + y = 5, x - y = 1
b = np.array([5, 1])                                   # right-hand side
print(np.linalg.solve(A, b))                           # [2. 1.]: x = 2, y = 1
T = np.array([[1, 0, 1], [1, -1, 0], [0, 1, 1]])       # the traffic system (3 equations, 3 unknowns)
print(round(np.linalg.det(T), 9))                      # 0.0: no single answer
print(np.linalg.matrix_rank(T))                        # 2: only 2 of the 3 equations are really independent

9Where this goes

  • Next (7.B.9): row reduction, the step-by-step method that solves systems of any size by working on the augmented matrix, and that finds every solution when there are infinitely many.
  • Later in this book: planes meeting in 3D (7.B.10), rank and independence, which count how many equations really carry information (7.B.12), and least squares in the Undergraduate tier, which finds the best answer when a system has no exact solution.
  • In the world: engineers solve systems with millions of unknowns to simulate bridges, weather and airflow; GPS solves one to find your position; and traffic planners balance flows exactly as in §7.

10Words to know

System of linear equationsSeveral equations, each a sum of numbers times unknowns, to be true all at once.
Coefficient matrixA: the numbers in front of the unknowns, one row per equation, one column per unknown.
Unknown vectorx: the unknowns stacked in a column.
Right-hand sideb: the numbers after the equals signs, stacked in a column.
Augmented matrix[A | b]: A with b attached as an extra column. Row reduction (7.B.9) works on it.
Row pictureEach equation is a line (a plane in 3D); solutions are where they all meet.
Column pictureThe system asks how much of each column of A adds up to b.
Linear combinationA sum of stretched vectors, like x·col 1 + y·col 2.
Unique solutionExactly one answer. For a square A, it happens exactly when det A ≠ 0.
Cramer’s rulex = det(A with column 1 replaced by b) / det A, and likewise for each unknown.
