Chapter 3 · Algebra

Systems of Linear Equations

Two unknowns need two facts. Each fact is a line of possibilities; where the lines cross is the one answer that fits both.

Basics you are here Undergraduate Masters

On this page

  • See a system of equations as two lines, and its solution as the point where they intersect.
  • Solve a system three ways: graphing, substitution and elimination, and know when each is easiest.
  • Recognize the three possible outcomes: exactly one solution (lines cross), no solution (parallel lines), or infinitely many (the same line).
  • Turn a word problem with two unknowns into a system and solve it.

1Two facts, two unknowns

“Two numbers add up to 10.” That alone doesn’t pin them down: 7 and 3, 5 and 5, 12 and −2 all work. Every pair (x, y) with x + y = 10 is a point, and together those points form a straight line. “Their difference is 4” is a second line of possibilities. Only one pair fits both facts: the point where the lines cross, (7, 3).

Two or more equations that must be true at the same time form a system of equations, written with a brace. Its solution is every pair (x, y) that makes all the equations true at once. Graphically, that’s the intersection of the lines.

    2Three ways to solve

    MethodHowBest when
    GraphingDraw both lines and read off where they cross.You want to see the situation, or only need an estimate. Answers like (11/7, 9/7) are hard to read exactly off a grid.
    SubstitutionSolve one equation for one letter (say y = 10 − x), then substitute that expression into the other equation, leaving one unknown.A letter already has coefficient 1 or −1, or an equation is already written as “y = …”.
    EliminationMultiply the equations so one letter has matching (or opposite) coefficients, then subtract (or add) the equations to cancel it.Both equations are in the form ax + by = c, especially with bigger coefficients.

    Why is elimination allowed? Both equations are true at the solution, so adding equal amounts to equal amounts (left side plus left side, right side plus right side) keeps things equal, exactly the balance from 3.B.2. On the graph, the one-variable equation that substitution or elimination produces (like x = 7) is a vertical line through the very same crossing point: the methods throw away a letter without losing the answer.

    3One, none, or infinitely many

    Two straight lines can meet in only three ways. They cross once: exactly one solution. They’re parallel (same steepness, different place) and never meet: no solution, and the algebra collapses to something false like 0 = 6. Or they’re the same line, with every point in common: infinitely many solutions, and the algebra collapses to 0 = 0. Watch a crossing point run away as one line turns toward parallel:

    4Word problems with two unknowns

    Name both unknowns, write one equation per fact, and solve. A classic: a farmyard has chickens and cows. You count 20 heads and 56 legs. With c chickens and w cows: c + w = 20 (heads) and 2c + 4w = 56 (legs).

      5Now, in symbols

      \[ \begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases} \qquad x = \frac{c_1 b_2 - c_2 b_1}{a_1 b_2 - a_2 b_1}, \quad y = \frac{a_1 c_2 - a_2 c_1}{a_1 b_2 - a_2 b_1} \]
      Elimination done once and for all. It works whenever the bottom number is not 0.
      \[ a_1 b_2 - a_2 b_1 = 0 \iff \text{the lines are parallel or the same line} \]
      That bottom number is the determinant of the coefficients (7.B.6): zero means the two lines point the same way.
      import numpy as np                              # NumPy: arrays of numbers
A = np.array([[3, 2], [2, -3]])                 # the coefficients: 3x + 2y and 2x − 3y
c = np.array([16, -11])                         # the right-hand sides
print(np.linalg.solve(A, c))                    # [2. 5.]  → x = 2, y = 5
print(np.linalg.det(np.array([[1, 2], [1, 2]])))  # 0.0: parallel lines, no single answer

      7Words to know

      System of equationsTwo or more equations that must all be true at the same time.
      Solution of a systemA pair (x, y), or more generally a set of values, that makes every equation true.
      IntersectionWhere two lines cross: the solution of their system.
      Graphing methodSolving by drawing both lines and reading the crossing point.
      SubstitutionSolve one equation for a letter and put that expression into the other equation.
      EliminationAdd or subtract (multiples of) the equations so one letter cancels.
      Parallel linesLines with the same slope that never meet: the system has no solution.
      No solution / infinitely manyThe algebra collapses to a false statement (0 = 6) or to 0 = 0 (the same line).
