Chapter 3 · Algebra

Variables and Expressions

A letter can stand for a number you don’t know yet, or for an amount that changes. Algebra is the art of calculating with those letters as if they were numbers.

Basics you are here Undergraduate Masters

On this page

  • Use a variable both as an unknown (a mystery number) and as a changing amount.
  • Build an expression from terms, and evaluate it by substituting a number, following the order of operations.
  • Simplify by combining like terms (3x + 2x = 5x, but 3x + 2 stays as it is).
  • Expand brackets with the distributive property, decide when two expressions are equivalent, and turn words into expressions.

1A letter for a number

“I’m thinking of a number. Double it and add 3, and you get 11.” The number is a mystery for now, so give it a name: call it x. A letter that stands for a number is a variable. Here it’s an unknown: one particular number we’re trying to find (it’s 4; solving for it is 3.B.2).

A variable can also stand for an amount that changes. A box holds 6 eggs, so n boxes hold 6n eggs: 6 when n = 1, 30 when n = 5. Here n isn’t secret, it just varies, and 6n describes every case at once.

A recipe of numbers, variables and operations, like 2x + 3 or 6n, is an expression. The pieces joined by + and − are its terms: 2x + 3 has the terms 2x and 3. The number multiplying a variable is its coefficient (2 in 2x), and a term with no variable is a constant (3). Writing 2x means 2 × x; algebra leaves out the × sign so it isn’t confused with the letter x.

3Evaluating, and the order of operations

To evaluate an expression, substitute a number for the variable and work it out. With x = 4, 2x + 3 = 2·4 + 3 = 11. To make sure everyone gets the same answer, mathematicians agreed on an order of operations:

OrderWhatExample
1Brackets (parentheses) first(2 + 3)·4 = 5·4 = 20
2Powers (exponents)2·3² = 2·9 = 18, not 6² = 36
3Multiply and divide, left to right12 ÷ 3·2 = 4·2 = 8
4Add and subtract, left to right2 + 3·4 = 2 + 12 = 14, not 5·4 = 20

The last row is the classic trap. In 2 + 3x, the 3 is glued to the x by multiplication, so it happens first. That’s why 2 + 3x is not 5x: try it below.

4Like terms

Terms with exactly the same variable part are like terms: 3x and 2x are like terms, and 3 bars plus 2 bars is 5 bars, so 3x + 2x = 5x. But 3x and 2 are not like terms: 3 bars and 2 squares can’t become 5 of anything, so 3x + 2 is already as simple as it gets. Simplifying means combining all the like terms: 2x + 3 + x − 1 = 3x + 2. Use the “Like terms” preset in the tiles to watch it happen.

5The distributive property

3(x + 2) means three copies of (x + 2): three bars and six squares, so 3(x + 2) = 3x + 6. The multiplier outside the brackets multiplies everything inside. As an area: a rectangle 3 tall and (x + 2) wide splits into a 3-by-x piece and a 3-by-2 piece. This is the distributive property, a(b + c) = ab + ac, and using it to remove brackets is called expanding.

6From words to symbols

Word problems describe expressions in English. Translate one chunk at a time, and check with a small number. Watch the order in phrases like “3 less than n”: you start with n and take 3 away, so it’s n − 3, not 3 − n.

    7Now, in symbols

    \[ a(b + c) = ab + ac, \qquad a(b - c) = ab - ac \]
    The distributive property: the multiplier reaches every term inside the brackets.
    \[ ax + bx = (a + b)x, \qquad -(x - c) = -x + c \]
    Combining like terms is the distributive property read backwards; a minus sign in front of brackets flips every sign inside.
    \[ a + b = b + a, \quad ab = ba, \quad (a + b) + c = a + (b + c), \quad (ab)c = a(bc) \]
    Order and grouping don’t matter for adding or for multiplying (but they do for subtracting and dividing).

    Computer algebra systems do this symbol-pushing automatically. In Python, the SymPy library expands and simplifies just like the tiles:

    from sympy import symbols, expand, simplify   # SymPy: algebra with symbols, not just numbers
x = symbols('x')                               # declare x as a symbol (a variable)
e = 2*x + 3 + x - 1                            # an expression with like terms
print(simplify(e))                             # 3*x + 2      (like terms combined)
print(expand(3*(x + 2)))                       # 3*x + 6      (distributive property)
print(e.subs(x, 4))                            # 14           (evaluate at x = 4)
print(simplify((2 + 3*x) - 5*x))               # 2 - 2*x: not zero, so 2 + 3x and 5x are different

    9Words to know

    VariableA letter that stands for a number: an unknown to find, or an amount that changes.
    UnknownA variable standing for one particular number we don’t know yet.
    ExpressionNumbers, variables and operations combined, like 2x + 3. It has a value, but no equals sign.
    TermA piece of an expression separated by + or −: 2x and 3 in 2x + 3.
    CoefficientThe number multiplying a variable: 2 in 2x. In x it is 1; in −x it is −1.
    ConstantA term with no variable, like 3.
    Evaluate (substitute)Replace the variable with a number and work out the value.
    Order of operationsBrackets, then powers, then multiply/divide, then add/subtract (left to right within each level).
    Like termsTerms with the same variable part, like 3x and −x. Only like terms combine.
    SimplifyRewrite an expression in its shortest equivalent form by combining like terms.
    Zero pairA positive and a negative of the same tile (x and −x, or 1 and −1): together they make 0.
    Distributive propertya(b + c) = ab + ac. Using it to remove brackets is expanding.
    Equivalent expressionsExpressions that have the same value for every value of the variable, like 3(x + 2) and 3x + 6.
