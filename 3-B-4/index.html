Functions

A function is a rule that gives every input exactly one output. Put the same thing in, and you always get the same thing out.

Basics you are here Undergraduate Masters

On this page

  • Tell a function from a relation that isn’t one, using arrow diagrams, tables and the vertical line test.
  • Read and use function notation: what f(3) means, how to evaluate it, and why f(a + 1) is not f(a) + 1.
  • Find the domain (the allowed inputs) and the range (the outputs that come out).
  • Read a graph: where it is increasing or decreasing, its maximum and minimum, its zeros, and every input that gives a chosen output.

1One input, one output

A vending machine is a rule. You press a button (the input) and a snack drops out (the output). What makes it a good machine is that it’s predictable: press A1 today, tomorrow or next year, and you always get the same snack.

That is exactly what mathematicians mean by a function: a rule that gives every input exactly one output. Two different buttons may give the same snack (both A2 and B1 give pretzels), and that’s fine. What is not allowed is one button that sometimes gives one snack and sometimes another. Any pairing of inputs with outputs is called a relation; a function is a relation that never breaks the one-output rule.

2Arrows and points

With numbers, every arrow “x goes to y” is an ordered pair (x, y), and every ordered pair is a point on a grid. So the arrow diagram and the graph are two pictures of the same thing. The set of all points (x, y) is the graph of the function.

On the graph, an input with two outputs shows up as two points stacked one above the other. That gives a quick check called the vertical line test: slide a vertical line across the picture. If it ever touches the graph in two places, the graph is not a function. Several inputs sharing one output (called many-to-one) only puts points side by side at the same height, which a vertical line never catches twice.

3Naming a rule: f(x)

Functions get names, usually a single letter like f, g or h. Then f(x), read “f of x,” means the output of f when the input is x. This is called function notation. If f(x) = 2x + 3, then f(4) is what comes out when 4 goes in: 2·4 + 3 = 11. Working that out is called evaluating the function.

Careful: the brackets in f(x) are not multiplication. f(4) does not mean f × 4. It means “feed 4 to f.” To evaluate, replace every x in the rule with the input, in brackets, then work it out. The brackets matter when the input is negative: if g(x) = x² − 1, then g(−3) = (−3)² − 1 = 9 − 1 = 8.

The input is also called the independent variable (you choose it freely) and the output the dependent variable (it depends on the input). On a graph, the input runs across and the output runs up, so f(x) is the height of the graph above x.

4Domain and range

The domain is the set of inputs a function accepts. The range is the set of outputs that actually come out. Picture squashing the graph flat: pushed straight down onto the x-axis, the graph’s shadow is the domain; pushed sideways onto the y-axis, its shadow is the range.

Three things usually shrink a domain. You can’t divide by zero, so 1/x refuses x = 0. A negative number has no real square root, so √x refuses negative x. And the situation itself can forbid inputs: you can’t line up 2.5 tables or throw a ball for −1 seconds.

5Reading a graph

A graph answers questions in two directions. Across, then up: pick an input, go up to the graph, read the output. That’s evaluating. Up, then across: pick an output, run a horizontal line at that height, and read every input where it meets the graph. That’s solving f(x) = some value, and there can be zero, one or several answers.

A graph also shows its shape at a glance. Where it rises from left to right, the function is increasing; where it falls, it is decreasing. Its highest point is the maximum and its lowest is the minimum. Where it crosses the x-axis, the output is 0; those inputs are the zeros of the function.

6Functions in the world

A thrown ball’s height depends on time: one moment, one height. The rule h(t) = h₀ + vt − 5t² (in metres and seconds, rounding gravity to 10 m/s²) works for any t, but the story only makes sense from the throw until the ball lands. So the domain is set by the situation, and the moment it lands is a zero: h(t) = 0.

Some functions jump. A taxi charges a starting fee plus a fixed amount for each mile started, so the price stays flat for a while, then jumps. This is a step function. At each jump the graph has a filled dot (this price includes that exact distance) and an open dot (this price doesn’t). The dots matter: if both ends were filled, the exact distance where the jump happens would get two prices, and the vertical line test would fail.

7Traps and non-examples

Three mistakes come up again and again. Each one is a misreading of the one-output rule or of the notation.

Compare

Look alike, behave differently

✓ Many-to-one is fine

−2 and 2 both go to 4 under x². Each input still has one output. Sharing an output breaks nothing.

✕ One-to-many is not

“Which number squares to 4?” sends 4 to both −2 and 2. One input, two outputs: not a function.

✕ f(a + 1) ≠ f(a) + 1

With f(x) = x², f(2 + 1) = 9 but f(2) + 1 = 5. The first steps right along the graph; the second lifts the output by 1.

Also: f(x) is never f times x, and the vertical line test is the one for functions. A horizontal line hitting twice (like x² at height 4) is allowed; that test is about undoing a function, which comes in 3.B.13.

8Now, in symbols

\[ f : X \to Y,\qquad x \mapsto f(x) \]
A function f from a set X of inputs to a set Y assigns to each x in X exactly one value f(x) in Y.
\[ \text{Function:}\quad x_1 = x_2 \;\Longrightarrow\; f(x_1) = f(x_2) \]
The one-output rule. (The reverse is not required: different inputs may share an output.)
\[ \text{graph}(f) = \{\,(x, f(x)) : x \in \text{domain}\,\},\qquad \text{range}(f) = \{\, f(x) : x \in \text{domain}\,\} \]
The graph is all the pairs; the range is all the outputs that actually occur.
\[ \frac{1}{x}:\ x \neq 0 \qquad \sqrt{x}:\ x \ge 0 \qquad [a, b] = \{a \le x \le b\},\quad (a, b) = \{a < x < b\} \]
Common domain limits, and interval notation: square brackets include the end, round brackets leave it out (the filled and open dots).
\[ f(x) = x^2:\quad f(a+1) = (a+1)^2 = a^2 + 2a + 1 \;\ne\; a^2 + 1 = f(a) + 1 \]
Substitute the whole input, in brackets, for every x.

Programming languages borrow the word, but a code “function” is only a function in the math sense if the same input always gives the same output:

import random                      # random numbers, to build a rule that is NOT a function

def f(x):                          # a true function: the output depends only on the input
    return 2 * x + 3               # f(4) is 11 every single time

def sticky_button(x):              # the sticky vending button from section 1
    return random.choice([x, -x])  # the same input can give different outputs

print([f(4) for _ in range(5)])             # [11, 11, 11, 11, 11]: one output per input
print([sticky_button(4) for _ in range(5)]) # e.g. [4, -4, 4, 4, -4]: two outputs, not a function

10Words to know

FunctionA rule that gives every input exactly one output.
RelationAny pairing of inputs with outputs. A function is a relation with one output per input.
InputWhat goes into a function; the value of x.
OutputWhat comes out; the value f(x).
Ordered pairAn input and its output written (x, y); a point on the graph.
Graph of a functionAll the points (x, f(x)) drawn on a grid.
Vertical line testA graph is a function exactly when no vertical line meets it more than once.
Many-to-oneDifferent inputs sharing the same output. Allowed in a function.
Function notationWriting f(x) for “the output of f at input x.” Not multiplication.
EvaluateWork out the output for a given input by substituting it, in brackets, into the rule.
Independent variableThe input, chosen freely; drawn across.
Dependent variableThe output, which depends on the input; drawn up.
DomainThe set of allowed inputs. The graph’s shadow on the x-axis.
RangeThe set of outputs that actually occur. The graph’s shadow on the y-axis.
Increasing / decreasingThe graph rises / falls as you move to the right.
Maximum / minimumThe highest / lowest output on the graph (or on part of it).
ZeroAn input where the output is 0; where the graph meets the x-axis. Also called a root.
Step functionA function that stays flat and then jumps, like a fare charged per started mile.
