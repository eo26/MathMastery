Matrices of Any Size: Adding, Scaling and the Transpose

A matrix doesn’t have to be square. Any table of numbers is one, and three simple operations, adding, scaling and flipping, work on all of them.

Basics you are here Undergraduate Masters

On this page

  • Read a matrix’s size (m × n: rows by columns) and name any entry aij.
  • Add and scale matrices entry by entry, and know when adding is impossible.
  • Flip a matrix with the transpose, and spot symmetric matrices.
  • Tell when a product AB of non-square matrices is defined, and what size it is.

1Any table is a matrix

A shop chain’s weekly sales report is a grid: one row per store, one column per product. Strip off the labels and you have a matrix: a rectangle of numbers. Until now our matrices were square (2×2, 3×3) because they were moves of the plane or of space. In general a matrix can have any number of rows and any number of columns.

Its size is written m × n, “m by n”: rows first, then columns. Three stores and four products make a 3 × 4 matrix. Each number is an entry, named by its row and column: a23 is the entry in row 2, column 3 (the same order again: row, then column). A matrix with one row is a row vector; one with a single column is a column vector, the kind we have been using all along.

Two matrices of the same size can be added: add the entries in matching spots. Week 1 plus week 2 is the two-week total, store by store and product by product. Any matrix can be scaled: kA multiplies every entry by k. And any matrix can be transposed: AT turns rows into columns, so the report sorted by store becomes a report sorted by product. Entry aij moves to position (j, i), and an m × n matrix becomes n × m.

2Shapes decide what’s allowed

Adding needs exactly the same size: a 3 × 4 table and a 3 × 3 table have spots with nothing to pair with, so A + B is simply undefined. Scaling and transposing always work.

Multiplying is pickier, and different. In 7.B.5, the entry in row i, column j of AB was row i of A dotted with column j of B. A dot product needs the two lists to be the same length, so the number of columns of A must equal the number of rows of B. Write the sizes side by side: (m × n)(n × p). The inner numbers must match, and the outer numbers give the size of the answer, m × p. That is also why AB can exist while BA doesn’t.

3Symmetric matrices

A road atlas has a mileage table: the distance from town i to town j, for every pair. The distance from Ashford to Easton is the same as from Easton to Ashford, so entry (i, j) equals entry (j, i), and flipping the table changes nothing. A matrix with AT = A is called symmetric: it is a mirror image of itself across its main diagonal, the entries a11, a22, … running from top-left to bottom-right. Only square matrices can be symmetric. Travel times with one-way streets or uphill roads aren’t symmetric, and the transpose shows exactly where.

4A picture is a matrix

A black-and-white digital photo is a grid of pixels, each a number for its brightness. So a photo is a matrix, and matrix operations are photo edits. Scaling by 1.5 brightens it. Adding half of one photo to half of another blends them. Subtracting every entry from the maximum makes a negative. The transpose flips the picture across its diagonal, which is not the same as rotating it.

5Traps and non-examples

Compare

Easy to get wrong

✕ Different sizes don’t add

A 2 × 3 and a 3 × 2 matrix hold six numbers each, but the spots don’t line up. A + B is undefined (though A + BT works).

✕ AB existing doesn’t mean BA does

(2 × 3)(3 × 4) works and gives 2 × 4. Turned around, (3 × 4)(2 × 3) has inner sizes 4 and 2: undefined.

✕ Transpose isn’t a rotation

The transpose mirrors across the diagonal, so the F comes out back to front. A quarter-turn keeps it readable. They are different moves.

6Now, in symbols

\[ A = [a_{ij}]_{m\times n} = \begin{pmatrix} a_{11} & a_{12} & \cdots & a_{1n}\\ \vdots & & & \vdots\\ a_{m1} & a_{m2} & \cdots & a_{mn}\end{pmatrix} \]
m rows, n columns; aij sits in row i, column j.
\[ (A + B)_{ij} = a_{ij} + b_{ij}, \qquad (kA)_{ij} = k\,a_{ij}, \qquad (A^{\mathsf T})_{ij} = a_{ji} \]
Adding needs equal sizes. AT is n × m.
\[ (AB)_{ij} = \sum_{k=1}^{n} a_{ik}\,b_{kj}, \qquad (m\times n)(n\times p) = m\times p \]
Row i of A dotted with column j of B. The inner sizes must match.
\[ (A^{\mathsf T})^{\mathsf T} = A,\quad (A+B)^{\mathsf T} = A^{\mathsf T} + B^{\mathsf T},\quad (kA)^{\mathsf T} = kA^{\mathsf T},\quad (AB)^{\mathsf T} = B^{\mathsf T}A^{\mathsf T} \]
Transposing a product reverses the order, like socks and shoes in 7.B.7. Check the sizes: (m × p)T is p × m, and so is (p × n)(n × m).
\[ A \text{ is symmetric} \iff A^{\mathsf T} = A \iff a_{ij} = a_{ji} \text{ for all } i, j \]

Spreadsheets and data tools treat every table as a matrix, and the size rules are checked for you:

import numpy as np                        # numerical arrays

A = np.array([[12, 5, 8, 3],              # week 1: 3 stores (rows) by 4 products (columns)
              [ 9, 7, 6, 4],
              [15, 2, 9, 5]])
B = np.array([[10, 6, 7, 2],              # week 2: same shape
              [11, 5, 8, 3],
              [14, 3, 6, 6]])
print(A.shape, A[1, 2])                   # (3, 4) and 6: Python counts from 0, so this is a₂₃
print(A + B)                              # two-week totals, entry by entry
print(A.T.shape)                          # (4, 3): the transpose swaps rows and columns
print((A @ A.T).shape)                    # (3, 3): (3×4)(4×3), inner sizes match
A @ A                                     # error: (3×4)(3×4), inner sizes 4 and 3 don't match

8Words to know

MatrixA rectangle of numbers arranged in rows and columns.
Size (m × n)The number of rows, then the number of columns. Also called the dimensions or shape.
Entry aijThe number in row i, column j.
Row vector / column vectorA matrix with a single row (1 × n) or a single column (m × 1).
Square matrixSame number of rows and columns.
Matrix additionAdd entries in matching positions. Only for matrices of the same size.
Scalar multiplicationkA: multiply every entry by the number k.
Zero matrixAll entries 0. Adding it changes nothing.
UndefinedAn operation that has no meaning for the given sizes, like adding 3 × 4 to 3 × 3.
Transpose ATRows become columns: (AT)ij = aji. An m × n matrix becomes n × m.
Main diagonalThe entries a11, a22, … from top-left to bottom-right. The transpose leaves them in place.
Symmetric matrixA square matrix equal to its transpose: aij = aji.
Inner / outer sizesIn (m × n)(n × p), the inner sizes (n, n) must match; the outer ones give the result, m × p.
