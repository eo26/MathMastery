Inverse Functions

A function turns inputs into outputs. Its inverse turns them back. On a graph the inverse is the mirror image in the line y = x, and as a recipe it undoes the steps in reverse order, like taking off socks and shoes.

Basics you are here Undergraduate Masters

On this page

  • Understand the inverse function f⁻¹ as the function that undoes f: if f(a) = b, then f⁻¹(b) = a.
  • Find inverses by undoing the steps in reverse order, or by swapping x and y and solving.
  • See the graph of f⁻¹ as the reflection in y = x, with domain and range swapped.
  • Decide which functions have inverses: one-to-one functions, spotted with the horizontal line test, and fix the others by restricting the domain.
  • Check an inverse with composition: f⁻¹(f(x)) = x and f(f⁻¹(x)) = x.

1Running a function backwards

The function f(x) = 2x + 3 takes 4 to 11. Going backwards, from 11 to 4, is the job of the inverse function, written f⁻¹ (“f inverse”): f⁻¹(11) = 4. In general,

\[ f(a) = b \quad\Longleftrightarrow\quad f^{-1}(b) = a. \]

Careful with the notation: the −1 is not an exponent. f⁻¹(x) means “undo f”, not 1/f(x). (For numbers 3⁻¹ = 1/3; for functions it means the inverse.)

Think of f as a recipe: take x, multiply by 2, then add 3. To undo it, undo each step, in reverse order: subtract 3, then divide by 2. So f⁻¹(x) = (x − 3)/2. It’s the same as getting dressed: socks then shoes, so to undress, shoes off then socks off.

The algebra version: write y = 2x + 3, swap x and y (because the inverse swaps inputs and outputs), x = 2y + 3, and solve for y: y = (x − 3)/2.

2The mirror in y = x

Every point (a, b) on the graph of f becomes the point (b, a) on the graph of f⁻¹: the coordinates swap. Swapping coordinates is reflecting in the line y = x, so the graph of f⁻¹ is the mirror image of the graph of f in y = x. You met one pair in 3.B.10: y = x² (for x ≥ 0) and y = √x. Another pair is coming in 3.B.14: 2x and log₂ x.

Swapping also swaps the domain (allowed inputs) and range (possible outputs): the domain of f⁻¹ is the range of f, and the other way round. √x only accepts x ≥ 0 because x² only produces outputs ≥ 0.

3Not every function can be undone

f(x) = x² sends both 3 and −3 to 9. So what is f⁻¹(9)? There’s no single answer, and a function must give one output. A function has an inverse exactly when it is one-to-one: different inputs always give different outputs. On a graph, that’s the horizontal line test: no horizontal line crosses the graph more than once. (If one did, the mirror image would fail the vertical line test from 3.B.4 and wouldn’t be a function.)

The fix is to restrict the domain: keep only part of the graph that passes the test. x² on x ≥ 0 is one-to-one, and its inverse is √x. That’s exactly why √ means the principal (non-negative) root.

4Checking an inverse

Doing f and then f⁻¹ should change nothing. That’s the definition, written with composition (doing one function after another):

\[ f^{-1}\big(f(x)\big) = x \ \text{ for every } x \text{ in the domain of } f, \qquad f\big(f^{-1}(x)\big) = x \ \text{ for every } x \text{ in the domain of } f^{-1}. \]

For f(x) = 2x + 3 and f⁻¹(x) = (x − 3)/2: f⁻¹(f(x)) = ((2x + 3) − 3)/2 = x ✓. Some functions are their own inverse: 1/x and 6 − x are their own mirror images in y = x.

5Inverses at work

Whenever you know the answer and want the question, you need an inverse: what temperature in °C is 98.6 °F? How far did the taxi go for a $28 fare? How fast was the car that left 40 m of skid marks? Secret codes are functions too: encrypting is f, decrypting is f⁻¹, and a code that isn’t one-to-one can’t be decoded.

6Traps and non-examples

Compare

Easy to get wrong

✕ f⁻¹(x) = 1/f(x)

For f(x) = 2x + 3, the inverse is (x − 3)/2 (green), the mirror image. 1/(2x + 3) (red) is a different curve entirely: the −1 means “undo”, not “one over”.

✕ Undo in the same order

f: ×2, then +3. Undoing ÷2 first, then −3, gives x/2 − 3 (red), which sends 11 to 2.5, not 4. Reverse the order: −3, then ÷2.

✕ √(x²) undoes x²

Only for x ≥ 0. For x = −3: (−3)² = 9 and √9 = 3, not −3. x² fails the horizontal line test, so it has no inverse until you restrict it to x ≥ 0.

7Now, in symbols

\[ f(a) = b \iff f^{-1}(b) = a, \qquad f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x \]
\[ \text{one-to-one: } f(x_1) = f(x_2) \Rightarrow x_1 = x_2, \qquad \operatorname{dom} f^{-1} = \operatorname{ran} f, \qquad \operatorname{ran} f^{-1} = \operatorname{dom} f \]
\[ f(x) = ax + b \ \Rightarrow\ f^{-1}(x) = \frac{x - b}{a}, \qquad (g \circ f)^{-1} = f^{-1} \circ g^{-1} \]
\[ C = \tfrac59(F - 32), \qquad v = \frac{-0.21 + \sqrt{0.21^2 + 0.022\,d}}{0.011} \]
