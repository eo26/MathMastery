Chapter 9 · Probability

Expected Value

Weigh every outcome by its chance and add: the result is the average you’d get per try in the long run, and the point where the probabilities balance.

Basics you are here Undergraduate Masters

On this page

  • Compute an expected value as a weighted average: each value times its probability, all added up.
  • See it as the long-run average over many tries, and as the balance point of the probabilities.
  • Decide whether a game is a fair game by finding the expected net gain, and set a price or prize that makes it fair.
  • Compare choices by expected value, and see when risk, how much results spread out, matters too.

1The average in the long run

Roll a die many times and average the results. The rolls 1, 2, 3, 4, 5, 6 come up about equally often, so the average settles near (1 + 2 + 3 + 4 + 5 + 6) ÷ 6 = 3.5. That long-run average is the expected value of the roll. Notice that 3.5 can never actually be rolled. The expected value isn’t a prediction for the next try; it’s what the tries average out to.

A number decided by chance, like the result of a roll or the points from a shot, is called a random variable, often written X. Its expected value is written E(X), also called its mean.

2Weigh each value by its chance

A spinner pays 0 points half the time, 10 points a third of the time and 50 points a sixth of the time. Spin it 600 times: about 300 spins pay 0, about 200 pay 10 and about 100 pay 50. The total is about 0 + 2,000 + 5,000 = 7,000 points, or 7,000 ÷ 600 ≈ 11.67 per spin. Dividing by 600 early gives the rule. Each value is multiplied by its probability, and the products are added:

\[ E(X) = 0 \cdot \tfrac12 + 10 \cdot \tfrac13 + 50 \cdot \tfrac16 = 11.67. \]

This is a weighted average: values that are more likely count for more. Picture each probability as a weight hung on a beam at its value. The expected value is exactly where the beam balances.

3Fair games

A carnival game costs $2. Roll a die: a 6 wins $10, anything else wins nothing. What happens on average? Look at the net gain, what you win minus what you paid: +$8 with probability ⅙, −$2 with probability ⅚.

\[ E(\text{net gain}) = 8 \cdot \tfrac16 + (-2) \cdot \tfrac56 = \tfrac{8 - 10}{6} \approx -0.33. \]

On average you lose about 33 cents a game, and the stall keeps it. A game is a fair game when the expected net gain is exactly 0: neither side gains in the long run. This one would be fair if a 6 paid $12, or if a game cost $10 ÷ 6 ≈ $1.67. Some multiple-choice tests are designed this way: +1 for a right answer and −⅓ for a wrong one. With four options, a blind guess has expected score ¼ · 1 + ¾ · (−⅓) = 0, so guessing gains nothing on average. Rule out one option first, and a guess has a positive expected value.

4Choosing, and when risk matters

Expected value is a natural way to compare choices you’ll face many times. A basketball team choosing between a two-pointer made 50% of the time (expected 1 point per shot) and a three-pointer made 36% of the time (expected 1.08 points) gains by taking more threes, over a season. But two choices with the same expected value can feel very different. Ten points for sure and a coin flip for 0 or 20 both have E = 10, but the coin flip has much more risk: its results spread far from the average. When you only get one try, and losing would hurt, the safer choice can be the sensible one even if its expected value is a little lower. 5When the formula is hard: simulate

How many times, on average, do you roll a die until the first 6? There’s no short list of outcomes: it could take 1 roll, or 2, or 30. Later you’ll prove the answer is exactly 6, but a simulation finds it in seconds:

import random                                   # Python's random-number tools
trials = 100_000                                # how many times to repeat the experiment
total_rolls = 0                                 # rolls used across all experiments
for _ in range(trials):                         # repeat the experiment many times
    rolls = 0                                   # rolls in this experiment so far
    while True:                                 # keep rolling...
        rolls += 1                              # ...count this roll
        if random.randint(1, 6) == 6:           # stop at the first 6
            break
    total_rolls += rolls                        # add this experiment's count
print(total_rolls / trials)                     # long-run average: about 6.0

6Traps

Compare

Easy to get wrong

✕ Averaging the values

The spinner pays 0, 10 or 50. The plain average (0 + 10 + 50) ÷ 3 = 20 ignores that 0 comes up half the time. Weighted by the chances, E = 11.67.

✕ Forgetting the cost

The carnival game pays $10 ÷ 6 ≈ $1.67 per game on average. That looks good until you subtract the $2 you paid to play: the net gain is about −$0.33 a game.

✕ Expecting the expected value

The expected number of children in a family here is 1.7, but no family has 1.7 children. E is the long-run average, not a likely or even possible single result.

7Now, in symbols

If a random variable X takes values x₁, x₂, …, xₙ with probabilities p₁, p₂, …, pₙ (which add to 1):

\[ E(X) = x_1 p_1 + x_2 p_2 + \dots + x_n p_n = \sum_{i=1}^{n} x_i\, p_i \]
\[ \text{balance: } \sum_{i} (x_i - E(X))\, p_i = 0, \qquad \text{fair game: } E(\text{net gain}) = 0 \]
\[ E(aX + b) = a\,E(X) + b, \qquad E(X + Y) = E(X) + E(Y) \]

The first line in the middle row is the balance: the weights on either side of E pull equally. The last line says expected values add. Paying $2 to play shifts every net gain by −2, so it shifts the expected value by −2 too, and the expected total of two dice is 3.5 + 3.5 = 7.

9Words to know

Random variableA number decided by chance, such as a roll or the points from a shot. Written X.
Expected valueE(X): each value times its probability, all added up.
MeanAnother name for the expected value of a random variable.
Weighted averageAn average where each value counts in proportion to its weight (here, its probability).
Long-run averageThe average result per try over very many tries. It settles on E.
Balance pointWhere a beam with the probabilities as weights would balance: E.
Net gainWhat you win minus what it cost to play.
Fair gameA game whose expected net gain is 0.
RiskHow far results tend to spread from the average. Measured precisely later by the standard deviation.
