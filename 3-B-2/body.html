Solving Linear Equations

An equation is a balance. Do the same thing to both sides and it stays balanced, so you can strip away everything around the unknown until it stands alone.

Basics you are here Undergraduate Masters

On this page

  • Read an equation as a balance, and find its solution: the value that makes both sides equal.
  • Solve linear equations with inverse operations, done to both sides: one-step, two-step, and with x on both sides.
  • Handle brackets, fractions and decimals, and always check by substituting back.
  • Set up equations from words, and rearrange formulas to solve for any letter.

1An equation is a balance

An expression, like 3x + 5, is a value. An equation says two expressions are equal: 3x + 5 = x + 13. For most values of x that’s false (with x = 1: 8 ≠ 14). The value that makes it true is the solution, and finding it is solving the equation. Here it’s x = 4: 3·4 + 5 = 17 and 4 + 13 = 17.

Think of a balance scale with the two sides on its two pans. It’s level because the sides are equal. You can add or remove the same amount on both pans, or split both into the same number of equal groups and keep one group each, and it stays level. Every legal step does the same thing to both sides. The goal is to leave x alone on one side; then the other side reads off its value. An equation where x appears only to the first power (no x², no 1/x) is called linear, and this always works for it.

    2Undo in reverse order

    Each step uses an inverse operation, the move that undoes another: subtracting undoes adding, dividing undoes multiplying. In 2x + 1 = 9, the x was first doubled, then had 1 added. Undo them in reverse, like taking off shoes before socks: subtract 1 (2x = 8), then divide by 2 (x = 4).

    When x is on both sides, first gather the x terms on one side by subtracting x’s from both, then proceed as before. It’s usually easiest to move the smaller number of x’s, so the coefficient that’s left is positive. Then always check: substitute your answer into the original equation and see that both sides match. A check catches almost every slip.

    3Brackets, fractions and decimals

    Brackets: either expand them with the distributive property (3.B.1), or, if a single number multiplies the whole side, divide both sides by it. Fractions and decimals: multiply both sides by a number that clears them all (the least common denominator, or 10 for one decimal place), so you’re back to whole numbers. Step through some examples:

      4From words to an equation

      Name the unknown, write each fact as an expression, set them equal, solve, and check the answer against the words.

      • Three consecutive whole numbers add up to 72. Call the smallest n; the others are n + 1 and n + 2. So n + (n + 1) + (n + 2) = 72, which is 3n + 3 = 72, so 3n = 69 and n = 23. The numbers are 23, 24, 25 (check: 72 ✓).
      • A taxi charges a 3-dollar pickup fee plus 2 dollars per kilometer, and the ride cost 19 dollars. With k kilometers: 3 + 2k = 19, so 2k = 16 and k = 8 km.
      • A rectangle is 5 cm longer than it is wide, and its perimeter is 38 cm. Width w, length w + 5: 2w + 2(w + 5) = 38, so 4w + 10 = 38, 4w = 28, w = 7. It’s 7 cm by 12 cm.

      5Rearranging formulas

      A formula is an equation with several letters. The same balance moves solve it for any one of them: treat the others as if they were numbers. This is called rearranging (or changing the subject of) the formula.

        6Now, in symbols

        \[ \text{If } A = B \text{ then } A + c = B + c,\quad A - c = B - c,\quad cA = cB,\quad \frac{A}{c} = \frac{B}{c}\ (c \ne 0) \]
        The properties of equality: whatever you do to one side, do to the other. Never divide by zero.
        \[ ax + b = cx + d \;\Longrightarrow\; (a - c)\,x = d - b \;\Longrightarrow\; x = \frac{d - b}{a - c} \quad (a \ne c) \]
        Every linear equation in one unknown can be put in this form and solved in one line.

        A computer can solve equations symbolically too:

        from sympy import symbols, Eq, solve          # SymPy: algebra with symbols
x = symbols('x')                               # the unknown
print(solve(Eq(3*x + 5, x + 13), x))           # [4]
print(solve(Eq(x/3 + 2, 6), x))                # [12]
F, C = symbols('F C')                          # letters in a formula
print(solve(Eq(F, 9*C/5 + 32), C))             # [5*F/9 - 160/9]  (= 5/9 (F - 32))

        8Words to know

        EquationA statement that two expressions are equal, like 3x + 5 = x + 13.
        SolutionA value of the variable that makes the equation true.
        SolveFind all the solutions.
        Linear equationAn equation where the variable appears only to the first power.
        Inverse operationThe operation that undoes another: − undoes +, ÷ undoes ×.
        Both sidesThe rule of solving: any move must be done to both sides to keep the balance.
        CheckSubstitute the answer into the original equation and confirm both sides are equal.
        Least common denominatorThe smallest number every denominator divides into; multiplying by it clears the fractions.
        Rearrange a formulaSolve a formula for one of its letters, like t = d/r from d = rt.
