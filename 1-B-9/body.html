Chapter 1 · Numbers & Arithmetic

Why We Invented Each New Kind of Number

Every new kind of number was invented for the same reason: someone wrote down a simple question the old numbers couldn’t answer. Five questions, five kinds of number, and the last one turns out to be a turn.

  • See why each set sits inside the next one.

1A question the old numbers can’t answer

Numbers began with counting: 0, 1, 2, 3, … Add two counts and you get another count, so the question 2 + 3 = x always has an answer. But ask x + 5 = 3, and the counting numbers are stuck. No count plus 5 makes 3.

Mathematicians don’t give up there. They invent the missing numbers, the negatives, so the question has an answer. Then a new question breaks the bigger system, and they invent again. Each new kind of number answers a question the old kind couldn’t, and keeps every old number inside it.

2The first three rungs: count, go below zero, cut

Natural numbers (ℕ) are the counting numbers 0, 1, 2, 3, … (some books start at 1). You can always add them, and multiply them. You can’t always subtract.

Integers (ℤ) add the negatives: …, −2, −1, 0, 1, 2, … In 1.B.1 they were the points left of 0 on the number line. Now subtraction always works. You can’t always divide: 3x = 2 has no integer answer.

Rational numbers (ℚ) are all the fractions a/b of integers (with b ≠ 0), like 2/3, −5/4 and 7 = 7/1. In 1.B.3 they filled the line so densely that there’s always another one between any two. Now you can add, subtract, multiply and divide (except by 0) and never leave ℚ. A set where an operation never takes you outside is closed under that operation.

Each set is a subset of the next: every natural number is an integer, and every integer is a fraction (5 = 5/1). The new sets don’t replace the old ones; they wrap around them.

3A length no fraction can name

The fractions are everywhere on the line. Surely every point is a fraction? Draw a square with sides of length 1. By the Pythagorean theorem, its diagonal d satisfies d² = 1² + 1² = 2, so d = √2. Now swing the diagonal down onto the number line like a compass. It lands at a perfectly real point, a little past 1.4.

Which fraction is it? Try cutting the line into finer and finer pieces below. Every time, √2 falls in a gap between two neighbouring fractions, never exactly on one.

Trying fractions can never prove that none works, because there are infinitely many to try. But a short argument can. It was known to the ancient Greeks.

Why no fraction squares to 2

  1. Suppose some fraction did: √2 = a/b. Cancel common factors first, so a and b are not both even.
  2. Square both sides: 2 = a²/b², so a² = 2b². That makes a² even.
  3. An odd number times itself is odd, so if a² is even, a itself is even. Write a = 2k.
  4. Then (2k)² = 4k² = 2b², so b² = 2k². By the same reasoning, b is even too.
  5. Now a and b are both even, but we made sure they weren’t. The only way out: no such fraction exists.

A number that isn’t a fraction is irrational. √2, √3, √5 and π are all irrational, and their decimals go on forever without ever settling into a repeating block (compare 1/3 = 0.333… in 1.B.3). Put the rationals and the irrationals together and you get the real numbers (ℝ): every point on the number line, with no gaps at all.

4The last rung: a number that is a turn

The real numbers seem to have everything. But try x² = −1. A positive number squared is positive; a negative squared is also positive (−3 × −3 = 9); 0² = 0. No real number works.

Here’s the key, from 1.B.2: multiplying by −1 flips the line around 0. Picture that flip as a half turn, spinning the line 180° about 0. Then we want a number i where doing it twice is a half turn. That’s a quarter turn: 90°. A quarter turn lifts the line off itself, so the new number lives above the line, one unit up. That’s i, the imaginary unit. Multiplying by i turns every point a quarter turn counterclockwise around 0, and two quarter turns make the half turn: i² = −1.

The numbers now fill a whole plane: a + bi sits a steps along the real line and b steps up. These are the complex numbers (ℂ). The name “imaginary” is just history; they are as real a tool as negatives were.

Is this the end? Remarkably, yes, for equations like these. The Fundamental Theorem of Algebra says every polynomial equation (things like x³ − 2x + 7 = 0) has a solution in ℂ. No new question of that kind forces another rung.

5Now, in symbols

The ladder, with the subset sign \(\subset\) meaning “sits inside”:

\[ \mathbb{N} \;\subset\; \mathbb{Z} \;\subset\; \mathbb{Q} \;\subset\; \mathbb{R} \;\subset\; \mathbb{C} \]
Each set solves an equation the one before couldn’t: \(x+5=3\), \(3x=2\), \(x^2=2\), \(x^2=-1\).
\[ \mathbb{Q} = \left\{ \tfrac{a}{b} \;:\; a, b \in \mathbb{Z},\; b \ne 0 \right\}, \qquad \sqrt{2} \notin \mathbb{Q} \]
“\(\in\)” means “is a member of”; \(\notin\) means “is not.”
\[ i^2 = -1, \qquad i\,(a + b\,i) = -b + a\,i \]
The point \((a, b)\) moves to \((-b, a)\): exactly a quarter turn counterclockwise.

6Where this goes

  • Next (Chapter 2): sets, subsets and the proof by contradiction you just used for √2 become tools of their own in Logic, Sets & Proof.
  • Later in this book: the gap-free real line is what makes limits and calculus work (Chapters 6 and 8). Turning by i grows into the unit circle and rotations (Chapter 5) and into eigenvalues of matrices (Chapter 7).
  • In the world: negatives for temperatures and elevations, fractions for measuring, irrationals for diagonals and circles (π), and complex numbers for anything that rotates or oscillates: sound, light, electricity and waves.

7Words to know

Natural numbers (ℕ)The counting numbers 0, 1, 2, 3, … (some books start at 1).
Integers (ℤ)The natural numbers and their negatives: …, −2, −1, 0, 1, 2, …
Rational numbers (ℚ)Fractions a/b of integers with b ≠ 0. Their decimals terminate or repeat.
Irrational numberA real number that is not a fraction, like √2 or π. Its decimal never ends and never repeats.
Real numbers (ℝ)Every point on the number line: the rationals and irrationals together.
Imaginary unit (i)The number with i² = −1. Multiplying by i is a quarter turn.
Complex numbers (ℂ)Numbers a + bi: points in a plane, with the real line as one axis.
Set / subsetA collection of things; a subset is a set sitting entirely inside another (ℤ ⊂ ℚ).
Closed under an operationDoing the operation never takes you outside the set (ℤ is closed under subtraction; ℕ isn’t).
