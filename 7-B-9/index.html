Solving Systems by Row Reduction

Three safe moves on the rows of a matrix solve any system of linear equations, of any size, and say plainly when there’s no answer or endless answers.

Basics you are here Undergraduate Masters

On this page

  • Use the three row operations (swap two rows, scale a row, add a multiple of one row to another) on the augmented matrix [A | b].
  • See why they never change the answer: the lines turn, but they keep passing through the same point.
  • Reach row echelon form (a staircase of pivots) and then reduced row echelon form, where the answer can be read off.
  • Spot no solution (a row 0 0 | 5) and infinitely many (a free variable), and find an inverse by reducing [A | I].

1Elimination, kept tidy

In 3.B.6 you solved two equations by elimination: add a multiple of one equation to the other so a variable cancels. Row reduction is the same idea, done on the augmented matrix from 7.B.8, one row per equation, so it never gets messy and works the same way for 2, 3 or 3000 unknowns.

There are only three moves, the row operations:

  1. Swap two rows: write the equations in a different order.
  2. Scale a row by a number that isn’t 0: multiply both sides of one equation by it.
  3. Add a multiple of one row to another row: the elimination step.

The goal is to make zeros under (and then above) a diagonal of 1s, until each row says just one thing, like x = 2.

2Why the answer never changes

Watch the picture while you work. A swap only trades the colors. A scale doesn’t move the line at all: 2x + y = 5 and 4x + 2y = 10 are the same line. An add turns one line, but it turns it around the crossing point: any point on both old lines satisfies both old equations, so it satisfies their sum too. The crossing point never moves; the lines just turn until they’re a vertical line x = … and a flat line y = ….

Each move can also be undone by another move of the same kind (swap back, scale by 1/k, subtract what you added), so no solution can be lost or gained. That’s why scaling by 0 is forbidden: it wipes out an equation and can’t be undone. Each row operation is the same as multiplying by a simple invertible matrix on the left, an elementary matrix, which is why matrices and row operations fit together so neatly.

3The staircase: row echelon forms

The first nonzero number in a row is its pivot (outlined in amber on the workbench). Reduction happens in two passes:

  • Going down: work column by column. Make the pivot a 1 (swap a row up if the spot is 0, then scale), and clear every number below it to 0. When done, the pivots form a staircase going down and to the right, with zeros underneath. That’s row echelon form (REF). At this point you could already finish by back substitution: solve the last equation, plug it into the one above, and so on. This half is called Gaussian elimination.
  • Going up: from the last pivot back to the first, clear every number above each pivot. Now each pivot is a 1 with zeros all around it in its column: reduced row echelon form (RREF), and each row reads off one answer. Doing both passes is Gauss–Jordan elimination.

The workbench’s status line shows when you’ve reached each form. Any sequence of legal moves that gets to RREF gives the same RREF, so there’s no wrong order, only shorter and longer routes.

4When the staircase has a gap

Try the “No solution” and “Infinitely many” presets. Two things can happen when a column has no pivot:

  • A row turns into 0 0 | 5. That row says 0x + 0y = 5, which is impossible, so the system has no solution. In the picture, the lines were parallel all along.
  • A row turns into 0 0 | 0. That row says 0 = 0: true, but no help. One equation was a copy (or a mix) of the others. A variable with no pivot in its column is a free variable: you can choose it freely, and the others follow. So there are infinitely many solutions, written with a parameter, such as (x, y) = (2 − 2t, t).

For a square system, a full staircase (a pivot in every column) is the same as det A ≠ 0 and exactly one solution (7.B.8). Row reduction is also how computers find determinants: every swap flips the sign, every scale multiplies it, and the add step doesn’t change it at all (it’s a shear, 7.B.6).

5Finding an inverse: reduce [A | I]

Solving Ax = b for many different b’s at once just means putting several columns after the bar. Put all the columns of the identity there, and reducing [A | I] solves Ax = e1, Ax = e2, … together. Those answers are the columns of A−1, so when the left side becomes I, the right side has become A−1. Another way to see it: the row operations, multiplied together, are exactly the move that turns A into I, which is A−1, and the right side records that move by applying it to I.

6A parabola through three points

Through any two points with different x’s there’s exactly one line. Through any three, there’s exactly one parabola y = px² + qx + r. Each point gives one equation in the unknown numbers p, q, r: the point (2, 3) says 4p + 2q + r = 3. Three points, three equations, one 3×3 system. Designers, engineers and spreadsheet trendlines do this constantly.

7Hitting three nutrition targets

8Currents in a circuit

A battery drives current through three resistors. Two rules from physics give the equations. At a junction, the current that flows in equals the current that flows out (like the traffic in 7.B.8). Around any closed loop, the battery’s voltage equals the sum of the voltage drops, where each resistor drops current × resistance (Ohm’s law, V = IR). Three unknown currents, three equations.

9Now, in symbols

\[ R_i \leftrightarrow R_j, \qquad R_i \to kR_i \;(k \neq 0), \qquad R_i \to R_i + kR_j \;(i \neq j) \]
The three row operations. None of them changes the set of solutions.
\[ [\,A \mid \mathbf{b}\,] \;\longrightarrow\; \text{REF} \;\longrightarrow\; \text{RREF} = [\,I \mid \mathbf{x}\,] \quad\text{when there is exactly one solution} \]
Gaussian elimination reaches REF; Gauss–Jordan continues to RREF.
\[ \begin{bmatrix} 0 & 0 & \cdots & 0 \mid c \end{bmatrix},\; c \neq 0 \;\Rightarrow\; \text{no solution}; \qquad \text{a column with no pivot} \;\Rightarrow\; \text{a free variable} \]
How to read the end result.
\[ [\,A \mid I\,] \;\longrightarrow\; [\,I \mid A^{-1}\,] \]
Reducing A to I turns I into the inverse.

For a system with n unknowns, row reduction takes about n³/3 multiplications: a few seconds by hand for 3, a millisecond on a laptop for 1000. Python’s SymPy library does exact fractions, like the workbench:

from sympy import Matrix                               # exact arithmetic, fractions included
M = Matrix([[2, 1, -1, 8], [-3, -1, 2, -11], [-2, 1, 2, -3]])   # an augmented matrix [A | b]
R, pivots = M.rref()                                   # reduced row echelon form, and the pivot columns
print(R)                                               # Matrix([[1, 0, 0, 2], [0, 1, 0, 3], [0, 0, 1, -1]])
print(pivots)                                          # (0, 1, 2): a pivot in every column, so one solution
A = Matrix([[2, 1], [1, 1]])
print(A.row_join(Matrix.eye(2)).rref()[0])             # [I | A^-1] = Matrix([[1, 0, 1, -1], [0, 1, -1, 2]])

11Words to know

Row operationSwap two rows, scale a row by a nonzero number, or add a multiple of one row to another. Never changes the solutions.
Augmented matrix[A | b]: the coefficients and the right-hand side, one row per equation.
PivotThe first nonzero entry of a row, once the matrix is in echelon form. Usually made into a 1.
Row echelon form (REF)Pivots step down and to the right like a staircase, with zeros below each pivot and zero rows at the bottom.
Reduced row echelon form (RREF)REF, plus every pivot is 1 with zeros above it too. Each row reads off an answer.
Gaussian eliminationRow-reduce to REF, then finish by back substitution.
Gauss–Jordan eliminationRow-reduce all the way to RREF.
Back substitutionSolve the last equation first, then plug its answer into the one above, and so on up.
Free variableA variable whose column has no pivot. It can be chosen freely, giving infinitely many solutions.
Elementary matrixThe matrix that performs one row operation when you multiply on the left.
