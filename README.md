# MathMastery

An interactive online math textbook that takes a student from zero to master's-level mathematics.
Every page builds intuition with interactive explorers and clear visualizations before formulas.
Written for students from middle school through PhD. Designed for desktop browsers.

## Structure

- Pages are identified as `chapter.tier.section` (e.g. `1.B.4`). Tiers: **B**asics, **U**ndergraduate, **M**asters.
- Each page lives in its own folder (`1-B-4/`):
  - `body.html` — the page's own source (styles, markup, script)
  - `index.html` — the built page (do not edit by hand)
- `shared/` — parts every page uses:
  - `head.html` — fonts, MathJax and the book-wide CSS
  - `toc.js` — **the table of contents: the single source of truth for page order and links**
  - `nav.js`, `nav.css` — the Contents menu and Previous/Next cards
- `index.html` — the home page (contents), generated by `make_home.py`

## Building

```bash
python3 build_all.py --site     # build every page for this site (relative links)
python3 make_home.py            # rebuild the home page from shared/toc.js
python3 build_all.py            # build for publishing as Claude artifacts instead
```

`build_page.py <folder> "<title>" [--site]` builds a single page. `pages.json` lists every page's folder,
title and Claude artifact id.

## Adding a page

1. Create `<ID>/body.html`.
2. Add the page to `shared/toc.js` (`built: true`) and to `pages.json`.
3. Run `python3 build_all.py --site && python3 make_home.py`, then commit.
