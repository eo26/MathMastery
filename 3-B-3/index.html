Inequalities and Absolute Value

An equation is a balanced scale; an inequality is a tipped one. Most of the balancing moves still work, with one surprise: multiplying by a negative number flips the tip.

1Not equal, but which way?

Rules are often limits, not exact values. “You must be at least 48 inches tall to ride.” “The speed limit is 65.” An inequality compares two amounts: x < 5 (less than), x ≤ 5 (less than or equal to, “at most”), x > 5 (greater than), x ≥ 5 (greater than or equal to, “at least”). The ride rule is h ≥ 48.

An equation like x + 3 = 8 usually has one solution. An inequality like x + 3 < 8 has endlessly many: every number less than 5. We draw the solution set on a number line as a shaded ray. The dot at the boundary is open (hollow) when the boundary is left out (<, >) and closed (filled) when it’s included (≤, ≥). Interval notation writes the same thing with brackets: (−∞, 5) for x < 5, and [48, ∞) for h ≥ 48. A round bracket means “not included”, a square one “included”, and ∞ always gets a round bracket because you can never reach it.

2Solving: the tipped balance

Picture a balance that is tipped: the heavier side is the bigger side. Adding or subtracting the same amount on both sides doesn’t change which side is heavier, and neither does multiplying both sides by a positive number (doubling both weights keeps the heavier one heavier). So you solve an inequality with exactly the moves from 3.B.2.

Except one. Multiply both sides by −1: 3 < 5 becomes −3 and −5, and now −3 is the bigger one. Multiplying or dividing by a negative number reverses the order, so you must flip the inequality sign. On the number line, multiplying by −1 is a mirror through 0, and a mirror swaps left and right. To check an answer, pick a test point in the shaded region and plug it into the original inequality; then try one outside.

    3“And”, “or”, and absolute value

    Two conditions can be joined. “And” means both must hold: “older than 12 and younger than 18” is 12 < x < 18, the numbers between. On the number line it’s where the two shaded rays overlap. “Or” means at least one holds: x < 0 or x > 10 is everything outside the gap, where either ray is shaded. These are compound inequalities.

    The absolute value |x| is the distance from x to 0, so it is never negative: |5| = 5 and |−5| = 5. More usefully, |x − a| is the distance between x and a. That turns absolute value problems into distance questions:

    • |x − 3| = 2: the points exactly 2 away from 3, so x = 1 or x = 5.
    • |x − 3| < 2: closer than 2 to 3, so 1 < x < 5, an “and”.
    • |x − 3| > 2: farther than 2 from 3, so x < 1 or x > 5, an “or”.

    And |x − 3| < −1 has no solutions at all, since a distance can’t be negative.

    4Rules, limits and tolerances

    Turning a rule into an inequality is mostly about the words. “At least” and “no less than” mean ≥. “At most”, “no more than” and “up to” mean ≤. “Between” is an “and”. “Give or take” and “within” are absolute value: a bolt that must be 10 mm long, give or take 0.2 mm, satisfies |L − 10| ≤ 0.2. And the situation decides what numbers count: you can invite 18 guests, but not 18.6.

    5Traps and non-examples

    Compare

    Easy to get wrong

    ✕ Forgetting to flip

    −2x < 6. Dividing by −2 must flip: x > −3. Keeping “<” gives x < −3, exactly the wrong half. Test x = 0: −2·0 = 0 < 6 ✓, and 0 > −3.

    ✕ “And” that can’t happen

    x < 1 and x > 4: the rays don’t overlap, so no number works. Written as 4 < x < 1 it looks fine but is empty. Joined with “or”, it would be a real solution set.

    ✕ |x − 3| > 2 is not 1 < x < 5

    “Farther than 2 from 3” is the outside: x < 1 or x > 5. “Less than” gives the inside, “greater than” the outside.

    6Now, in symbols

    \[ a < b \;\Rightarrow\; a + c < b + c, \qquad a < b,\ k > 0 \;\Rightarrow\; ka < kb, \qquad a < b,\ k < 0 \;\Rightarrow\; ka > kb \]
    Adding anything keeps the order. Multiplying by a positive keeps it; by a negative reverses it.
    \[ x < 5 \iff x \in (-\infty, 5), \qquad -2 < x \le 5 \iff x \in (-2, 5], \qquad x < 0 \text{ or } x > 10 \iff x \in (-\infty, 0) \cup (10, \infty) \]
    Interval notation. ∪ (“union”) joins the pieces of an “or”.
    \[ |x| = \begin{cases} x & x \ge 0 \\ -x & x < 0 \end{cases} \qquad |x - a| = \text{distance from } x \text{ to } a \]
    \[ |x - a| = r \iff x = a \pm r, \qquad |x - a| < r \iff a - r < x < a + r, \qquad |x - a| > r \iff x < a - r \text{ or } x > a + r \quad (r > 0) \]

    Checking a solution set by testing many points is exactly what a computer is good at:

    import numpy as np                        # numerical arrays

x = np.linspace(-10, 10, 2001)            # 2001 test points from −10 to 10, 0.01 apart
ok = -2 * x + 5 >= -1                     # True where the inequality holds, False elsewhere
print(x[ok].min(), x[ok].max())           # -10.0 3.0: the solutions run up to 3, so x ≤ 3
near = np.abs(x - 3) < 2                  # “closer than 2 to 3”
print(x[near].min(), x[near].max())       # about 1.01 and 4.99: the open interval (1, 5)

    7Where this goes

    • Next (3.B.4): functions, where the domain (the allowed inputs) is often described by inequalities like x ≥ 0.
    • Later in this book: inequalities in two variables shade half a plane; linear programming finds the best point in a region cut out by many of them; and in calculus, “within ε” (|x − a| < ε) is the heart of the definition of a limit (8.B.1).
    • In the world: speed limits, age and height rules, budgets and weight limits, manufacturing tolerances, safe ranges for medicine, temperature and pressure, and error bars on any measurement.

    8Words to know

    InequalityA statement comparing two amounts with <, ≤, > or ≥.
    Solution setAll the numbers that make an inequality true; usually a ray or an interval.
    Open / closed dotOn a number line: the boundary is left out (open, for < and >) or included (closed, for ≤ and ≥).
    Interval notationBrackets for a range: [ ] includes the end, ( ) leaves it out; ∞ always gets ( ).
    Flip the signReverse the inequality when multiplying or dividing both sides by a negative number.
    Test pointA number plugged into the original inequality to check whether it is a solution.
    Compound inequalityTwo conditions joined by “and” or “or”.
    “And” (intersection)Both must hold: the overlap, usually the numbers between.
    “Or” (union, ∪)At least one holds: everything shaded in either.
    Absolute value|x|: the distance from x to 0. Never negative.
    Distance |x − a|How far x is from a on the number line.
    Absolute value equation|x − a| = r: two solutions, a ± r (for r > 0).
    Absolute value inequality|x − a| < r (between) or > r (outside).
    ToleranceHow far a measurement may be from its target: “10 mm ± 0.2”.
